# Automation-Introduction-Python

Python automation exercises for files and spreadsheets | Exercícios de automação em Python para arquivos e planilhas

---

## 🇺🇸 English

### About the Mini-Course
This repository contains the materials and practical exercises developed for the **"Introduction to Automation with Python"** mini-course, presented during an **Academic Week**. 

The course introduces Python as a practical tool to automate repetitive daily computer tasks, focusing on real-world scenarios such as organizing files and processing spreadsheets.

### Topics Covered
* **Python Basics:** Essential syntax and logic for scripting.
* **File Management:** Automating folder organization, renaming, and moving files.
* **Spreadsheet Processing:** Reading, editing, and generating spreadsheets automatically.

### Prerequisites
* [Python 3.x](https://python.org) installed on your machine.
* Basic programming logic (helpful, but not mandatory).

### How to Run
1. Clone this repository:
   ```bash
   git clone https://github.com
   ```
2. Navigate to the project folder:
   ```bash
   cd Automation-Introduction-Python
   ```
3. Install the required libraries (if applicable):
   ```bash
   pip install -r requirements.txt
   ```
4. Run the desired script:
   ```bash
   python script_name.py
   ```

## 🇧🇷 Português

### Sobre o Minicurso
Este repositório contém os materiais e exercícios práticos desenvolvidos para o minicurso **"Introdução à Automação com Python"**, ministrado durante uma **Semana Acadêmica**.

A proposta apresenta o uso do Python como ferramenta prática para automatizar tarefas repetitivas no computador, partindo de situações reais do dia a dia, como organizar arquivos e processar planilhas.

### Conteúdo Abordado
* **Fundamentos de Python:** Sintaxe essencial e lógica para criação de scripts.
* **Manipulação de Arquivos:** Automação para organizar pastas, renomear e mover arquivos.
* **Processamento de Planilhas:** Leitura, edição e geração automática de dados em planilhas.

### Pré-requisitos
* [Python 3.x](https://python.org) instalado na máquina.
* Noções básicas de lógica de programação (ajuda, mas não é obrigatório).

### Como Executar
1. Clone este repositório:
   ```bash
   git clone https://github.com
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd Automation-Introduction-Python
   ```
3. Instale as bibliotecas necessárias (se houver):
   ```bash
   pip install -r requirements.txt
   ```
4. Execute o script desejado:
   ```bash
   python nome_do_script.py
   ```
